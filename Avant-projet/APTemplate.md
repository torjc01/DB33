# Modèle d'Avant-projet 

**Titre provisoire:** ajouter le titre provisoire ou definitif de l'article

**Plan geographique:** indiquer quelle est l'étendue géographique du sujet de l'article

**Timeframe:** indiquer quelle est l'étendue temporelle que l'article analyse, e.g. contemporain, XIX siècle, antiquité, etc.

**Publique cible:** quel est le publique cible? Spécifiquement si l'article s'adresse à un publique exclusivement maçonnique ou plus large. 

**Langue primaire** langue principale dans laquelle l'article est écrit. 

**Sources de recherche:** indiquer quels seront les types de source d'information à rechercher. 

## Questions de recherche

Lister toutes les questions qui la recherche veut répondre. 

## Références 

Mentionner les références aux sources qui ont été consultées lors de la recherche. 

### Bibliographie 

Références bibliographiques, selon le Quarry Projet Style Guide, et par conséquence, le Chicago Style Guide. 

### Liens web

Liens à des pages web consultées. 

### Multimédia 

Référence a toute source multimédia utilisée dans la recherche.
